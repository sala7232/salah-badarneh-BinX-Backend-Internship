# BinX Tech Backend Internship - Week 1

## Overview

This repository contains all tasks and exercises completed during **Week 1** of the BinX Tech Backend Development Internship (.NET).

Week 1 focused on building a strong foundation in C#, .NET, Object-Oriented Programming, Collections, LINQ, Git, and GitHub workflow.



## Learning Objectives

- Set up the .NET development environment.
- Learn C# fundamentals.
- Practice Object-Oriented Programming (OOP).
- Work with Collections and LINQ.
- Understand async/await.
- Learn Git and GitHub workflow.
