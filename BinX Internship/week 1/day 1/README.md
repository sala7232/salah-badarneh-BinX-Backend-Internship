# Day 1 — Program Orientation & .NET Development Setup

Day 1 focused on understanding the BinX Backend Internship program, 
setting up the .NET development environment, and building the first 
console application.

## What I Did

- Installed and verified the .NET SDK using `dotnet --version`
- Installed Visual Studio Code and configured the C# Dev Kit extension
- Created a new console application called `HelloBinX` using the 
  `dotnet new console` command

- Created a GitHub repository to track my progress throughout the 
  internship
