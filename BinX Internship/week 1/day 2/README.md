# Day 2 — C# Fundamentals: Types, Variables & Control Flow

Day 2 focused on core C# concepts: value types vs reference types, 
variable copy behavior, control flow with switch expressions, and 
safely handling nullable input.

## What I Did

- Demonstrated value types (int, bool, double) and reference 
  types (string, array, custom class) using `GetType()`
- Showed the difference between copying a value type and copying a 
  reference type
- Built a grade classifier using a switch expression with four score 
  ranges
- Read user input safely using nullable reference types, with a 
  fallback default value
